# 01_rx_dump — 受信波形とプロトコル候補を調べる

> English: [README.md](README.md)

リモコンの信号を受信し、RAWの時間列、デコード候補、名前付きフィールドを表示します。送信例を選ぶ前に、まずこの例で信号を調べます。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 復調型赤外線受信モジュールの電源・GND・OUTを接続し、入力GPIOと反転設定を合わせます。
3. [01_rx_dump.ino](01_rx_dump.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `IRReceiver rx(32, true)` は受信器のOUTピンと信号の反転を指定します。一般的なactive-low出力を想定しているので、両引数を実際の基板とモジュールに合わせます。
2. `rx.begin()` で受信を開始し、`rx.read(r)` で完了した受信結果を取り出します。通常、falseは結果がまだない意味ですが、初期化できていない場合にもfalseになります。
3. `printRawMicros()` はtick値をマイクロ秒に換算して表示します。候補のループでは、`printDecodedCandidate()` でスコアとbitsを、`printDecodedFrame()` でプロトコル固有のフィールドを表示します。

## 確認できること

同じボタンを短く何度か押し、プロトコルとコマンドが安定するか確認します。長押しではリピートフレームが出ることがあります。候補がなくてもRAW波形の受信自体には成功している場合があります。

## 変更するときの注意

コメントアウトされた `setScoreThreshold()` は調査時に候補の採用条件を緩める設定です。スコアは順位付けであり、確率や機器の受理保証ではありません。似たプロトコルを比較する際はRAWも残します。

`IRReceiveResult::raw` は受信器の内部データを参照するviewです。次の `read()` や `end()` を越えて使う場合は、自分で確保した配列へtick列をコピーします。この例で `begin()` の戻り値を表示しない箇所も、受信が始まらない場合は最初にその成否を確認してください。
