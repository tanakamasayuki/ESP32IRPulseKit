# 06_ac_learn — エアコンの状態信号を受信して学習する

> English: [README.md](README.md)

長いエアコンのリモコン信号を受信し、設定内容と再送コードを表示します。受信専用の例なので、この例だけでは保存やエアコンの操作は行いません。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 復調型赤外線受信モジュールの電源・GND・OUTを接続し、入力GPIOと反転設定を合わせます。
3. [06_ac_learn.ino](06_ac_learn.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `rx.begin()` より前に、RAW専用、受信シンボル容量拡張、idle閾値をまとめて設定します。閾値は受信を終了する無音時間なので、まとめて受信したいバースト内部の隙間より長くします。
2. `ac::decodeAny(r.raw, &Serial)` はAC用デコーダを試し、認識した状態を表示します。ベンダの認識は、その全機種や全オプション項目への対応を意味しません。
3. `printSetterSnippet()` は編集用の論理フィールド設定例で、表現できない設定を失うことがあります。`printSendSnippet()` はデコードした状態バイトを保持します。未認識時はローカルヘルパーがRAW再送コードを出します。

## 確認できること

ボタンを1回押し、コピー前に `raw.len(ticks)` と `TRUNCATED` の有無を確認します。1回の操作で学習ブロックが複数出る場合は、idle閾値が内部ギャップより短い可能性があります。複数回の受信を比べてから再送データを選びます。

## 変更するときの注意

AC再送では既定の位相整合キャリアを使います。切り詰めがあれば初期化前に受信容量を増やし、idle閾値はsetterとハードウェアの制限内で調整します。任意の時間が受理されるわけではありません。RAW再送にも正しいキャリアと完全な波形が必要で、互換性の保証ではありません。ヘルパーを使用前の無名名前空間に置くのは、Arduinoのプロトタイプ生成に名前空間付き型の推測をさせないためです。

`IRReceiveResult::raw` は受信器の内部データを参照するviewです。次の `read()` や `end()` を越えて使う場合は、自分で確保した配列へtick列をコピーします。この例で `begin()` の戻り値を表示しない箇所も、受信が始まらない場合は最初にその成否を確認してください。
