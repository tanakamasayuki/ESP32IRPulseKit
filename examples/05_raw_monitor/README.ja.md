# 05_raw_monitor — RAW受信と取りこぼしを調べる

> English: [README.md](README.md)

プロトコルデコードを無効にして受信時間列を表示し、受信器の累積統計を確認します。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 復調型赤外線受信モジュールの電源・GND・OUTを接続し、入力GPIOと反転設定を合わせます。
3. [05_raw_monitor.ino](05_raw_monitor.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `begin()` より前の `setDecodeCandidates(0)` でRAW専用にします。このモードでデコード候補がないのは意図どおりです。
2. `r.truncated()` は波形が受信容量に収まらず途中で切れたこと、`r.rmtOverflow()` はRMTオーバーフローを示します。再送用データにする場合は無視できません。
3. `rx.stats()` はキューでの破棄、ハードウェアオーバーフロー、切り詰めの累積回数を返します。リモコン操作量やシリアル出力量を変え、値の増え方を比較します。

## 確認できること

受信が完了するたびに時間列と統計が出ます。まず単発の短押し、次に長い信号で試します。一部の受信に成功していても、カウンタの増加から欠落や不完全な出力を調べられます。

## 変更するときの注意

キュー破棄が増える場合は表示を減らすか、受信結果を速く処理します。長い信号は `begin()` 前の `setMaxRxSymbols()` と適切なidle閾値で調整します。信号内部の無音で分割されたデータは、容量だけ増やしても直りません。

`IRReceiveResult::raw` は受信器の内部データを参照するviewです。次の `read()` や `end()` を越えて使う場合は、自分で確保した配列へtick列をコピーします。この例で `begin()` の戻り値を表示しない箇所も、受信が始まらない場合は最初にその成否を確認してください。
