# 07_ac_send — エアコンの状態を組み立てて送信する

> English: [README.md](README.md)

Panasonic用AC状態をsetterで組み立て、温度変更と電源OFFの状態を送信します。一連の操作を繰り返すため、対応する実機があれば実際に動作します。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 赤外線LEDと適切な駆動回路を用意し、出力GPIOを配線に合わせます。
3. [07_ac_send.ino](07_ac_send.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `IRSender tx(4)` の出力を `tx.begin()` で準備します。この例は位相整合キャリアを既定のまま使います。組み込む際は、初期化失敗を処理してから送信を許可します。
2. `Panasonic::Frame` に電源、COOLモード、AUTO風量、温度を設定します。フレームは状態全体を表すので、温度を送ると他の設定も一緒に送られます。
3. `ac::send(tx, f)` はチェックサムを含めてRAWへ変換し、送信します。ループでは28度から26度までを送ったあと、電源をfalseにしてもう一度送ります。

## 確認できること

シリアルには `cool ...C`、`sent` または `send failed`、最後に `power off` が出ます。まず別の受信器で波形を確認します。ローカルの送信成功は家電からの受信応答ではありません。

## 変更するときの注意

実際のリモコンに合うFrame型を選び、必要な状態項目をすべて設定します。例の温度ループを置き換えるときは、繰り返し方と間隔も用途に合わせます。機種や状態形式が不明な場合は、元のリモコンを `06_ac_learn` で調べます。

`send()` はローカル送信完了を待つ呼び出しです。trueでも相手機器の受信や実行は確認できません。falseの際は初期化・GPIO・入力値・RMT資源を確認します。
