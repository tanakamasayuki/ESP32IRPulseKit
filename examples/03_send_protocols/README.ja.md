# 03_send_protocols — プロトコル別の送信ヘルパーを試す

> English: [README.md](README.md)

複数の内蔵リモコンプロトコルを順番に送信し、それぞれの送信結果を表示します。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 赤外線LEDと適切な駆動回路を用意し、出力GPIOを配線に合わせます。
3. [03_send_protocols.ino](03_send_protocols.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `tx.begin()` は内蔵プロトコル定義を補います。各 `bits::...()` ヘルパーは `send()` に必要なプロトコルID、ビット長、データを作ります。
2. `report(label, tx.send(...))` は各プロトコルのローカルな送信結果を表示します。呼び出しは記述順に実行され、最後のdelayは個々のコマンドではなく一巡全体の間隔を空けます。
3. 明示的に上書きしない限り、キャリアはプロトコル定義に従います。アドレスやコマンドを名前付きで扱う場合は、対応する `frames::...` 型と `toBits()` を使います。

## 確認できること

別の受信器で表示ラベルと受信内容を対応付けます。一部しか認識できない場合はRAWも確認します。1台の家電が全プロトコルに対応するわけではありません。

## 変更するときの注意

実用時は対象リモコンに合うヘルパーだけを残し、例の値を置き換えます。全ヘルパーの引数が同じアドレス／コマンド形式だと考えず、プロトコルヘッダのビット順とフィールド定義を確認します。

`send()` はローカル送信完了を待つ呼び出しです。trueでも相手機器の受信や実行は確認できません。falseの際は初期化・GPIO・入力値・RMT資源を確認します。
