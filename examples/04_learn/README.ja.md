# 04_learn — 再利用できるリモコン送信コードを作る

> English: [README.md](README.md)

受信したリモコン信号から、送信スケッチへコピーできるC++コードを表示します。この例自体は受信のみで、送信やフラッシュへの学習データ保存は行いません。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 復調型赤外線受信モジュールの電源・GND・OUTを接続し、入力GPIOと反転設定を合わせます。
3. [04_learn.ino](04_learn.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `rx.read(r)` で波形と候補を取得します。RAWは受信器のバッファを参照しているので、次のreadの前に処理します。
2. `r.candidate()` は最上位の候補を返し、一致がなければ `nullptr` になります。`printBitsSendSnippet()` はその候補を使うコンパクトな送信コードを表示します。
3. 一致がない場合は `printRawSendSnippet()` がtick配列とRAW送信コードを表示します。配列を含むコード全体を、設定済みの `IRSender` を持つスケッチへコピーします。

## 確認できること

ボタンを押すと `---- learned ----` とコードが出ます。短押しで数回取得して比較し、コピーしたコードの送信を別の受信器で確認します。

## 変更するときの注意

長押し中のリピートだけを学習すると、最初のコマンドが含まれない場合があります。RAWが記録するのは復調後のmark/space時間で、光のキャリア周波数ではありません。再送周波数はリモコン仕様や既知のプロトコルから選びます。長いエアコン信号には `06_ac_learn` を使います。

`IRReceiveResult::raw` は受信器の内部データを参照するviewです。次の `read()` や `end()` を越えて使う場合は、自分で確保した配列へtick列をコピーします。この例で `begin()` の戻り値を表示しない箇所も、受信が始まらない場合は最初にその成否を確認してください。
