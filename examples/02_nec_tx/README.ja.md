# 02_nec_tx — NECコマンドを送信する

> English: [README.md](README.md)

アドレスとコマンドからNEC信号を作り、赤外線LEDの駆動回路を通して繰り返し送信します。

## 準備と実行

1. [入門ガイド](../../docs/GUIDE_EXAMPLES.ja.md)で導入と配線を確認します。
2. 赤外線LEDと適切な駆動回路を用意し、出力GPIOを配線に合わせます。
3. [02_nec_tx.ino](02_nec_tx.ino)を開き、対象ボードを選んで書き込みます。シリアルモニタを115200 baudにします。

## コードの読み方

1. `IRSender tx(4)` は出力GPIOを選びます。LEDの電源を意味しません。`tx.begin()` はRMT送信器を準備するので、戻り値を確認してから送信を利用します。
2. `bits::nec(0x00ff, 0x34)` は `IRDecodedBits` を作ります。16進数の見た目から推測せず、受信例で調べたアドレスとコマンドへ置き換えます。
3. `tx.send(bits)` は値をエンコードして送信します。コメントアウトされた `NECFrame` は名前付きフィールドで組み立てて `toBits()` で変換する別の書き方です。どちらかを使います。

## 確認できること

シリアルモニタにはループごとに `sent` または `send failed` が出ます。別の基板で `01_rx_dump` を動かすと、家電の動作に頼らず送信したプロトコルとフィールドを確認できます。

## 変更するときの注意

delayはコマンド同士の間隔です。停止するまで送信を続けます。必要なキャリア周波数がわかる場合以外は、プロトコルによる自動選択を使います。`setCarrierHz()` の明示指定は自動選択を上書きします。

`send()` はローカル送信完了を待つ呼び出しです。trueでも相手機器の受信や実行は確認できません。falseの際は初期化・GPIO・入力値・RMT資源を確認します。
